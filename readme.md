# Obsidian Manga Reader

[English](#english) | [Русский](#русский)

---

## English

A manga reading plugin for Obsidian that lets you maintain a local manga library alongside your notes.

### Key Features

**📚 Local Library Management**
- Store manga inside your Vault (recommended, cross-platform) or link external folders (desktop)
- Track reading progress for each title
- Cross-platform support (tested on Android mobile)

**⚡ Fast & Reliable Reader**
- Custom virtual DOM engine with chapter metadata caching
- Two reading modes: page-by-page and infinite scroll (bidirectional)
- Flexible chapter indexing: neighbors only, extended preload, or background indexing

**📝 Title Notes & Covers**
- Auto-generated note for each title to store comments, thoughts, tags, and ratings
- Multiple cover images with slideshow support

**🌐 Localization**
- Interface available in English and Russian

### Library Sources

- **Inside Vault** (recommended): Cross-platform, reliable, syncs across devices
- **External Folders**: Desktop-only option for existing collections outside Obsidian

### Reading Modes

- **Page Mode**: Classic single-page navigation
- **Scroll Mode**: Continuous infinite scroll with seamless chapter transitions in both directions

The reader preloads and caches chapter data for fast navigation and instant reopening.

### Configuration

Customize reading mode, indexing strategy, reader width, library folders, language, and more in plugin settings.

## Русский

Плагин для чтения манги в Obsidian с поддержкой локальной библиотеки.

### Основные возможности

**📚 Управление библиотекой**
- Храните мангу внутри Vault (рекомендуется, кроссплатформенно) или подключайте внешние папки (десктоп)
- Отслеживайте прогресс чтения по каждому тайтлу
- Кроссплатформенная работа (проверено на мобильном Android)

**⚡ Быстрый и надежный ридер**
- Собственный движок на virtual DOM с кэшированием метаданных глав
- Два режима чтения: постраничный и бесконечный скролл (в обоих направлениях)
- Гибкая индексация глав: только соседние, расширенная предзагрузка или фоновая индексация

**📝 Заметки и постеры**
- Автоматическая заметка для каждого тайтла: комментарии, мысли, теги, рейтинг
- Поддержка нескольких постеров с показом в режиме слайдшоу

**🌐 Локализация**
- Интерфейс на английском и русском языках

### Источники библиотеки

- **Внутри Vault** (рекомендуется): кроссплатформенность, надежность, синхронизация между устройствами
- **Внешние папки**: вариант для десктопа, если коллекция находится вне Obsidian

### Режимы чтения

- **Страница**: классическая навигация по одной странице
- **Лента**: непрерывный бесконечный скролл с плавными переходами между главами в обоих направлениях

Ридер заранее загружает и кэширует данные глав для быстрой навигации и мгновенного открытия.

### Настройки

Настраивайте режим чтения, стратегию индексации, ширину ридера, папки библиотеки, язык интерфейса и другие параметры в настройках плагина.
